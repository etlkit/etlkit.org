The open-source ETL toolkit for .NET.

EtlKit is a free, MIT-licensed ETL library for .NET. Move data between databases, files and message queues with a few lines of C# — readable, testable, and versioned in git with the rest of your code.

$ dotnet add package EtlKit
ImportOrders.cs 
var source = new CsvSource<Order>("orders.csv");
var clean  = new RowTransformation<Order>(o => { o.Email = o.Email.Trim(); return o; });
var dest   = new DbDestination<Order>(sqlConnection, "Orders");

source.LinkTo(clean).LinkTo(dest);
await source.ExecuteAsync(); await dest.Completion;

Code your ETL, not boilerplate.

Every pipeline is three steps: create the components, link them with LinkTo(), then execute the source and wait for the destination. Rows stream through TPL Dataflow buffers, so only the rows in flight are held in memory.

Build ETL in .NET

Write pipelines in your favourite .NET language, with your IDE, debugger and unit tests. Source, transformation and destination components compose into a flow.

Runs everywhere

Written in .NET Standard 2.0 and tested on Linux, macOS and Windows with current .NET. Embed it in a web app, a worker service or a console job.

Made for big data

Built on Microsoft's TPL Dataflow with per-component buffers and batched bulk writes — SqlBulkCopy on SQL Server, binary COPY on PostgreSQL.

Manage change

Track ETL logic in git, review it, and run it through your existing CI/CD. Control-flow tasks replace ADO.NET ceremony for DDL and SQL with one line each.

What teams build with it.

EtlKit fits wherever data has to move on a schedule or as it arrives, and the people who own that job already write .NET.

Reporting loads

Nightly or hourly loads from OLTP databases into a reporting store — SQL Server or PostgreSQL into ClickHouse, with lookups and aggregations on the way.

Table synchronisation

Keep a copy of a table in another database in step with its source: DbMerge inserts, updates and deletes only what changed.

Partner file imports

CSV, Excel and JSON files from partners or SFTP drops into your database, with malformed rows captured in an error table for follow-up.

Event ingestion

Kafka topics, MongoDB change streams or new rows in a PostgreSQL table, written to a database as they arrive and resumed from a checkpoint after a restart.

Moving off SSIS

Re-implement SSIS packages as C# that builds, tests and deploys with the rest of your services — and runs on Linux.

Enrichment

Call a REST API per row, or send batches to an OpenAI-compatible model to classify or extract fields, inside the same pipeline.

Resumable sources save their position through ICheckpointStore and continue from it after a restart (at-least-once). The PostgreSQL tail polls by transaction ID: it sees inserts and updates, but not deletes — it is not logical-replication CDC.

Hand-written code vs EtlKit.

What a typical data task takes when you write it from scratch on ADO.NET and client libraries, and what it takes with EtlKit.

Task By hand With EtlKit
Bulk load SqlBulkCopy with a DataTable on SQL Server, binary COPY on Postgres, batched INSERTs elsewhere — one code path per database. DbDestination<T> picks the fastest write path for the connection and batches rows for you.
Upsert / sync a table A staging table plus MERGE or ON CONFLICT in each SQL dialect, and a separate pass for deletions. DbMerge<T> with [IdColumn] and [CompareColumn]: full, no-deletions or delta mode, same code on five databases.
CSV → database A reader loop, type conversion, batching and try/catch around every bad line. CsvSource<T> → DbDestination<T>; bad rows go to LinkErrorTo().
Kafka → database A consumer loop, JSON deserialisation, batching writes and shutdown handling. KafkaJsonSource<T> → DbDestination<T> with a cancellation token.
Tail a Postgres table A polling query, a stored cursor, and care not to skip rows from transactions still in flight. PostgresXminTailSource<T> + CheckpointWriter with a DbCheckpointStore.
MongoDB changes → SQL A Watch() loop and your own storage for resume tokens. MongoChangeStreamSource<T> resumes from the token in its checkpoint store.

Code, or configuration.

With EtlKit.Serialization the same components can be declared in XML and loaded at runtime: element names are class names, child elements are properties. Change a pipeline without recompiling the host.

orders-flow.xml 
<EtlDataFlowStep>
  <Pipeline>
    <CsvSource><Uri>orders.csv</Uri></CsvSource>
    <ExpressionRowFiltration>
      <FilterExpression>Amount &gt; 0</FilterExpression>
    </ExpressionRowFiltration>
    <LinkTo>
      <DbDestination>
        <ConnectionManager type="PostgresConnectionManager">
          <ConnectionString>Host=db;Database=sales</ConnectionString>
        </ConnectionManager>
        <TableName>orders</TableName>
      </DbDestination>
    </LinkTo>
  </Pipeline>
</EtlDataFlowStep>

Is EtlKit the right tool?

EtlKit is a library for developers. If that is not what you need, one of these will serve you better.

EtlKit

A fork that continues the open-source 1.x lineage of the original ETLBox library by Andreas Lennartz, kept current with modern .NET and database drivers. As of 2.0, EtlBox.Classic was renamed to EtlKit to avoid package and namespace conflicts.
